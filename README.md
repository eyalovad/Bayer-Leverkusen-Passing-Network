Bayer Leverkusen’s Passing Network Centralisation and Match Outcomes
Were Bayer Leverkusen more likely to win when their players shared passing responsibilities more evenly? 
I explored this question using Bundesliga event data from the 2015/16 and 2023/24 seasons. 
In both seasons, the models suggested that higher centralisation was associated with a greater likelihood of winning, but the estimates were too uncertain to draw a firm conclusion.

David Sumpter’s Soccermatics was a helpful introduction to football analytics, and the passing network tutorial helped me create the networks for this project.

Extending the analysis to more seasons would help clarify whether there is a consistent relationship between passing network centralisation and match outcomes.
